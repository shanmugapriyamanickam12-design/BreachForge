# Task 01 — Cybersecurity Concept Identification

## Scenario 1

### Scenario

A company stores customer information on a database server. The server
is running outdated software with a known security weakness.

### Answer

**Asset:** Database server which stores the customer information

**Threat:** Attacker

**Vulnerability:** Outdated software

**Possible CIA Impact:** Confidentiality, Integrity, Availability

### Why?

The database which contains the customer information is the asset. If the attacker accessed the database, they can possibly modify/alter the information  which affects the confidentiality and integrity. They can also crash the database which can impact the availability of data.

## Scenario 2

### Scenario

An employee receives an email asking them to enter their company password
on a suspicious website.

### Answer

**Asset:** company credentials

**Threat:** Attacker

**Vulnerability:** Lack of cyber awareness

**Possible CIA Impact:** Confidentiality

### Why?

Company credentials are the most valuable asset. The attacker have the access to those credentials affects the confidentiality.


---

## Scenario 3

### Scenario

An attacker gains unauthorized access to a company's database and changes
customer information.

### Answer

**Asset:** Company database and customer information

**Threat:** Attacker

**Vulnerability:** -

**CIA Property Affected:** Integrity

### Why?

By unauthorized access the user can change/modify the customer information which severely affects the integrity of data.

# Short Answers

## 1. What do we call something valuable that needs protection?

Asset

## 2. What do we call a weakness that could be exploited?

Vulnerability

## 3. What do we call something that could potentially cause harm?

Threat

## 4. Which CIA property protects information from unauthorized access?

Confidentiality

## 5. Which CIA property protects information from unauthorized changes?

Integrity

## 6. Which CIA property ensures systems and information remain accessible?

Availability
